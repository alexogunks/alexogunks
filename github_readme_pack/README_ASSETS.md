# README Visual Assets

This pack uses externally hosted SVG/image endpoints to add visual polish to GitHub Markdown.

## Included assets

- **Capsule Render:** animated-style banner and footer.
- **Readme Typing SVG:** typing introduction.
- **Shields.io:** profile, project, and stack badges.
- **Skill Icons:** technology icon rows.
- **GitHub Readme Stats:** repository statistics and language cards.
- **Streak Stats:** contribution streak card.
- **Komarev:** profile view counter.

## Before publishing

1. Check that each external service is acceptable for your privacy and availability needs.
2. Replace placeholder project names, descriptions, and links.
3. Verify that your chosen language and technology icons match tools you actually use.
4. Stats services may be delayed, rate-limited, unavailable, or require configuration. The README should still make sense if a card fails to load.
5. Avoid adding secret tokens to image URLs or committing credentials.
6. Use repository-hosted screenshots for project-specific visuals whenever possible.

## GitHub profile README setup

GitHub displays a profile README when you have a public repository whose name exactly matches your username and whose root contains `README.md`.

For this account, create or update the public repository named `alexogunks` and put the contents of `PROFILE_README.md` into its root `README.md`.

Official instructions: https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme
